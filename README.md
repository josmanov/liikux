# Gymfinder

Simple Finland gym finder. Search gyms by city or name, open details, register/login, and save favorites.

## Stack

- **Client:** React + Vite + TypeScript (`client/`)
- **Server:** Express + TypeScript (`server/` — coming next)
- **Database:** PostgreSQL + Drizzle
- **Auth:** JWT + argon2

## Quick start (client for now)

```bash
cd client
npm install
npm run dev
```

Open the URL Vite prints (usually http://localhost:5173).
