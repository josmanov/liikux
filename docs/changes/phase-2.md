# Phase 2 — browse list + map (first part)

Branch: `upgrade/0-1-foundation-look` · Status: **waiting for your review (not committed)**

## What changed

| Change | Where | How it works |
|---|---|---|
| **List no longer feels a second behind the map.** | `features/browse/components/BrowseResultsList.tsx`, `GymResultCard.tsx` | Cause: every list row faded in with a delay of up to 0.5 s (`animationDelay = index × 28 ms`), and that replayed for every new row after each filter or distance change. Now the fade-in plays only once, when the list first appears. After that rows appear in the same frame as the map pins. Measured: list and pins now update in the same frame (about 40–90 ms), and rows have no animation after the first load. |
| **Own map style** in Liikux colours (graphite land, deep blue water, muted yellow motorways, dark green parks). Free, no API key, commercial use allowed (OpenFreeMap tiles). | `client/public/map/liikux-style.json`, generated by `scripts/build-map-style.mjs` | The script downloads OpenFreeMap's base style and repaints it. **To change colours, edit `PALETTE` at the top of the script and run `node scripts/build-map-style.mjs`.** `MAP_STYLE_URL` in `features/browse/utils/mapConstants.ts` points to it. |
| **Place and street names show up earlier** (neighbourhoods from zoom 10, villages 9, main streets 11, side streets 13.5). Road number shields removed. | same script | |
| **Pin click rules**. Before: every click zoomed the map to fit you and the gym, which jumped around. Now a click only selects the gym and highlights it in the list. The map moves only if the pin is near the edge or hidden under a button or card, and then it pans just enough. Zoom never changes. | `features/browse/utils/mapBounds.ts` (`isPointComfortablyVisible`, `revealGym`), `useBrowseMapMarkers.ts` | |
| **List click rules**: if the gym's pin is visible, it is only highlighted. If not, the map shows you and the gym together, so you see how far it is. | `pages/GymsPage.tsx` → `focusGymFromList()` | |

## Round 4: design pass (clean and harmonised)

The strong white outlines from round 3 were removed again. One system now applies everywhere:

| Rule | Where to change it |
|---|---|
| **Borders are hairlines.** Boxes are separated by their fill colour (`--surface`, `--surface-2`, `--surface-3`), not by loud outlines. | `--line`, `--line-strong`, `--outline` in `client/src/styles/tokens.css` |
| **One page gutter.** Header, home, browse, gym page and footer all use `padding: … var(--gutter)`: normal side padding on small screens, a centred 1600 px column on big ones. The header never jumps between pages. `scrollbar-gutter: stable` keeps it from shifting when a page has a scrollbar. | `--max-width`, `--gutter` in tokens.css; `index.css` |
| **Browse toolbar is one bar across the top**: title, search (260 px), filter buttons, clear; popular chips on a second row. The list and map start on the same line (this replaces the left-only toolbar, which left a dead area above the map). All controls are 40 px high with the same fill and border. | `features/browse/css/BrowseToolbar.css` |
| **List rows**: the favourite heart is a quiet round icon (no box around every heart, red when saved); chain label is small and muted, gym name is the strongest text; soft hover fill. | `features/browse/css/BrowseList.css` |
| **Map**: no light edge while tiles load; map credits are shown (required by OpenStreetMap) in a small dark style. | `BrowseMap.css`, `BrowseList.css` |
| **Front page**: bigger headline with the last word in yellow; larger search; a quiet "or browse all gyms" link instead of a second button; the four numbers are one strip with dividers; step cards with round yellow number badges; 12 cities in a tidy 6 × 2 grid; the same space between all sections. | `pages/HomePage.css`, `features/home/` |
| **Header helper buttons** (Puuttuuko sali?, Ilmoita virheestä) are quiet text buttons that light up on hover, so they do not compete with the navigation. | `components/HeaderFeedbackLinks.css` |

## Test it

1. Browse page, open **Etäisyys** and click 1 km, 5 km, 30 km, Kaikki: the list and the map should change together, instantly.
2. Zoom in on the map and click a pin: the map must stay still, and the gym is highlighted in the list.
3. Click a gym in the list whose pin is off screen: the map shows you and the gym.
4. Zoom to city level: neighbourhood and street names should be readable without zooming far.
